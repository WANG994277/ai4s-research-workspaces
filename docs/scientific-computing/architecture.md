# 科学计算实现决策

需求：在科研空间增设科学计算二级模块，覆盖计算任务、模型训练、模型推理、任务创建、运行详情与结果。当前项目未接计算集群，用户确认先实现前端和本地模拟流程。

候选：复用旧 `/compute-space` 原型；新增全套计算后端；在当前 `v1` 科研空间壳层内实现独立的本地任务读写模型。旧原型属于另一入口与视觉体系，直接嵌入会丢失当前空间上下文；真实后端超出本轮范围。选择第三项。

复用：Next.js App Router、现有 `BaselineShell`、科研空间上下文、Lucide、Recharts 与浏览器本地存储。未新增依赖。任务对象包含 `spaceId`，按空间隔离；服务端接入时将本地仓库替换为任务 API，保留页面、状态和动作接口。原型下载为示例结果，日志及运行状态明确标注为模拟。
