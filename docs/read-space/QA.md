# 读空间验收记录

范围：PRD V1.0 的八项读空间能力、研究任务中心、科研上下文、证据、研究产物及跨空间草稿。全部为可操作的前端模拟，数据本地保存。

## 已核验

- 首页：六个科研智能体、八种任务模板、科研问题、研究模式、课题关联、资料上传引用与任务恢复。
- 科研思路探索：计划执行、两个人工确认节点、五类产物、刷新恢复、来源页码、暂停与失败重试入口。
- 跨空间：确认研究范围与参数后传递完整计算草稿；算空间原生工作台接收并形成计算方案，做空间接收并生成实验方案。
- 任务隔离：切换课题不会显示其他课题任务；同一来源可以独立关联多个课题。
- 标准：五组条款差异分别人工确认并保存；在科研思路探索任务内操作不会覆盖主计划。
- 专利：技术空白保持候选属性，补充检索及验证证据保存至任务。
- 图表：模拟识别、人工校正、来源记录与真实 XLSX 下载；工作簿已通过 ZIP/XML 与 openpyxl 读取校验。
- 写作：基于素材生成正文、引用检查、正式报告人工确认；直接打开工作台不串用其他任务草稿。
- 图谱：实际任务资源、证据、方法、参数、研究产物关联展示及示例扩展。
- 检索→研读：URL 科研问题保留；所选两篇文献与分析范围正确传递，刷新恢复。
- 研读：方法卡产物、人工确认、AI 回答及 P3 证据定位；人工笔记与 AI 内容独立保存。
- 布局：七个专业工作台在 1440px 与 390px 无页面水平溢出；无浏览器运行错误。

## 静态验证

- 读空间组件、路由与领域测试定向 ESLint：通过。
- `node --import tsx scripts/check-read-space.ts`：通过。
- `pnpm build`：完整项目生产构建通过。

## 浏览器脚本

- `scripts/check-read-space-browser.js`：首页、研究流程、任务恢复、跨空间、课题隔离。
- `scripts/check-read-workspaces.js`：七个工作台桌面与窄屏布局。
- `scripts/check-read-interactions.js`：标准、专利、提取、写作、图谱操作。
- `scripts/check-read-reader.js`：检索选集、证据定位、笔记与写作隔离。

设置 `PLAYWRIGHT_MODULE` 可使用现有 Playwright 运行时；设置 `READ_SPACE_BASE_URL` 可验证独立预览服务。截图与详细断言保存在 `qa/`。
