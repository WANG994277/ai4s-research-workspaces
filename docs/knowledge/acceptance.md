# 科研知识库交付与验收

日期：2026-09-21。依据用户提供的《AI4S_科研知识库模块页面开发说明书_V1.0.md》。导航位置遵循用户消息：一级「知识库」紧接「读空间」，位于「算空间」之前。

## 已实现

- `/knowledge` 默认进入首个可访问知识库；支持 `/knowledge/:id/documents`、文档阅读器、`graph`、`chat`、`entries`。
- 一级导航、全局搜索和当前路由识别已接入；知识库使用模块内助手，顶部助手按钮也会打开当前知识库问答。
- 知识库目录分组/搜索/折叠/收藏，创建和编辑知识库，专业领域、范围、标签、封面、自动图谱及问答开关。
- 核心页签严格为文档、知识图谱、知识问答；知识条目、分类标签和配置通过更多菜单进入。
- 文档的正文/标题/作者/来源/标签搜索，多条件筛选、排序、收藏、批量问答、详情、重试、删除确认。
- 原件保存至 IndexedDB；本地多文件、文件夹、拖放入口；示例资产/课题/文献/标准专利引用；URL 来源和手工正文录入。
- 文献目录、原件预览/下载、正文检索、引用高亮、批注、标签、阅读要点、正文新版本及历史正文对照。
- 交互 SVG 图谱：实体/关系/来源/时间/标签过滤，缩放平移、方向/层级展开、实际关系路径、实体对比、节点与边证据回看。
- 正文词项、图谱关系、元数据融合检索；八种证据整理模式，多轮提问，按当前知识库和资料范围返回引用；无依据时明确显示证据不足。
- 正式知识条目可创建、编辑、筛选、保存引用及查询历史版本，也可作为问答资料来源。
- 标签分类、别名、统计、改名、合并和删除。操作明确作用于全部可编辑知识库，只读库保持原样。
- 知识证据可加入新版读空间的科研任务，生成任务、知识库资料引用、未核验证据与完整证据包。
- 本地保存失败保留草稿；同源其他窗口变更会同步，发现过期快照时拒绝覆盖并提示重试。

## 浏览器验收

独立生产预览：`http://127.0.0.1:3105/knowledge`（使用独立构建目录，避免开发热更新打断测试）。

已实际操作：

1. 创建「功能验收知识库」，确认空库导入引导。
2. 通过文件选择器导入 `fixtures/knowledge-import-check.md`，确认文档可用、图谱完成，作者显示未提供、课题显示未关联。
3. 使用正文中的 `KB-CHECK-0921` 检索并问答，确认真实引用、逻辑页与段落。
4. 保存问答为知识条目；点击引用进入阅读器，确认目标原文高亮并能返回问答。
5. 更新正文到v1.1并刷新，旧引用仍定位v1.0且原件下载入口保留；图谱使用v1.1正文。
6. 从选中证据创建科研任务，确认获得实际任务链接与证据包。
7. 点击图谱关系，核对来源原文、源版本及「共现不代表因果」说明；搜索「数字岩心」验证关联过滤。
8. 进入访问受限的知识库，确认无权限状态且导入禁用。
9. 在另一知识库询问验收标识，得到证据不足，没有泄漏验收库资料。
10. 指定不存在的知识条目历史版本，显示引用不可用，没有替换为当前正文。
11. 1440及1280宽度检查：无页面横向溢出，表格在内部滚动；预览页未捕获浏览器error日志。

测试数据只保存在对应预览地址的浏览器存储中；验收库保留用于复查。页面源代码未写入这些验收记录。

## 明确的原型边界

- 问答是可运行的本地证据检索与摘录整理，尚未接入生成模型、语义向量服务或真实外部数据库；页面有明确标识。
- 图谱通过本地科研词项和同段共现构建，所有关系带来源且待人工核验，不伪造因果关系。
- TXT、Markdown、CSV可本地建立文本索引。PDF、Office和图片保存原件，等待实际解析/OCR服务；可以人工补录正文。人工正文按逻辑页定位，不宣称对应原PDF页码。
- URL导入保存来源与用户提供的正文，不自动抓取网络内容。示例引用目录不是对CNKI、科研资产系统或其他外部平台的真实连接。
- 权限是本地原型的可读/可编辑状态演示，不能替代服务端鉴权或团队共享后端。

实际对接解析、模型和检索服务时，可替换文件处理与检索层；文档、版本、Evidence、问答及工作区的数据边界已拆分。
