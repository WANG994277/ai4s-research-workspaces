| 9、21 方案 Agent | /do-space/agent?plan=… | 设计计划、结构化 Artifact、参数来源、人工确认、路线比较、编辑、风险检查 |

| 原型评审 | 需求检查与 PRD 抽屉 | 稳定需求 ID、原始章节映射、编辑保存、当前页与完整文档下载 |

## 已验证

- 关键状态测试：未定版禁止任务创建，未确认参数禁止定版，版本隔离；维护设备、重叠/无效时段禁止预约；审批中预约禁止下发；异常未处置禁止推进/恢复；预约撤销后禁止推进；超设备量程禁止定版。
- 浏览器完整流程：新建 → 选择路线 → 确认参数 → 会签退回 → 重提 → 同意 → 定版 → 样品关联 → 预约 → 管理员确认 → 4 项人工审核 → 下发。
- 浏览器执行闭环：启动 → 记录参数变更 → 模拟异常 → 禁止恢复 → 提交处置 → 人工恢复 → 结果采集 → 分析/平滑 → 报告 → 结论确认 → 读/算双向回流。
- 已实际打开回流目标，显示对应研究任务与计算方案；刷新后执行、异常、参数变更、报告和回流记录保留。
- 样品登记、流转保存、抽屉关闭；PRD 编辑、保存、刷新恢复和下载文件内容检查。
- 浏览器验证 8 个旧入口均保留课题参数跳转至新做空间；切换到另一课题不显示原课题方案；冲突预约与维护设备的提交按钮均被禁用。
- 1440 宽完整界面检查；1280 宽预约页面根节点与主区域无横向溢出。
- 类型检查、ESLint、生产构建通过。此目录与脚本只记录做空间范围，其他既有模块的未提交工作保留。

## 明确的模拟范围

本版本是可连续演示的前端原型。AI 服务、审批、ELN/LIMS/iLOMS 连接、图像模型识别和实时设备执行均不接真实服务。二进制 PDF/Word 仅登记附件；表征数值清洗/平滑/归一化和 CSV 导入/导出在前端实际执行。图谱采用通用响应曲线，不冒充专业物相识别。
