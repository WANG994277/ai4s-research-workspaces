# AI4S 做空间演示指南

## 启动与入口

在项目根目录运行 `pnpm dev`，打开 [做空间](http://localhost:3000/do-space?projectId=PROJ-CCUS-01)。页面复用平台侧栏与课题选择器。推荐 1440 × 1050 或更大桌面窗口，1280 宽度也可使用。

示例课题为「CO₂ 加氢制甲醇催化剂研究」。做空间记录按课题隔离，设备目录为共享资源。切换课题保留此前的方案、任务、样品和结果。

## 从设计到结果回流

1. 首页点击「试用示例」，或输入自己的实验目标。可选择催化活性、页岩真三轴、材料稳定性模板；可引用读空间研究产物、算空间已完成任务，或上传已有方案。
2. 点击「生成实验方案」。三栏分别显示任务依据、设计过程、结构化方案。等待演示生成完成。
3. 点击「比较方案」，查看 A/B/C 的样品数量、参数覆盖、机时、风险与信息量；选择 C 可使用初始 18 份样品完成演示。
4. 「编辑方案」可修改目标、假设、材料、数量、对照组、步骤、设备、参数来源与安全要求。修改后重新确认参数与会签。
5. 进入「参数确认」，核对后点击「确认以上参数与来源」。进入审核与会签，填写说明并发起会签。
6. 可先模拟审核人「退回」或「要求修改」，再修改后重新提交；点击「模拟审核人同意」，由负责人「确认定版」。AI 参数未确认、会签未同意或参数超出已知设备量程时不能定版。
7. 点击「进入实验执行」，创建关联精确方案版本的任务，进入实验自动编排。
8. 勾选足够数量的已制备样品，选择执行设备与负责人。样品不足时前往样品工作台登记并准备样品。检查样品类型、批次与保存条件。
9. 点击「选择机时与提交预约」。演示从 2026-09-21 所在周开始排期，推荐选择 **2026-09-24 08:00–10:00**。填写方案、任务、样品、用途和负责人，确认提交。
10. 在「我的预约」点击「模拟审批通过」，确认后返回实验编排。
11. 逐项确认「样品条件」「设备与预约」「高风险实验」「实验前审核」，点击「确认并下发任务」，再确认正式下发（模拟）。
12. 进入实验任务，点击「开始执行（模拟）」。可记录参数变更，新旧值、原因、操作者、时间和审批确认都进入历史。
13. 点击「模拟实验异常」。任务被阻断，恢复按钮不可用。进入异常页，提交具体处置与复核结果；任务保持暂停，再人工确认恢复。
14. 点击「模拟完成实验并采集结果」，推进至表征分析并完成实验记录。原始测量数据在任务中可查看、下载。
15. 打开「表征分析」。可选择样品或批次，查看测量曲线、通用响应图谱、图像示意、样品对比、计算与实验对比、原始表格；可应用清洗、3 点移动平均、归一化转换。
16. 点击「生成实验报告」，复核或人工编辑实验结果 Artifact；点击「确认实验结论」。修改报告或处理流程后需重新确认。
17. 选择「用于模型校准 / 重新计算」或「补充文献研究」，再次确认回流。点击「打开下游草稿」，可在实际读空间任务或算空间方案中继续演示。回流保留实际参数、原始和处理后数据、异常、偏差、课题和来源编号。

## 其他演示入口

- **实验方案**：搜索、状态过滤、模板、版本历史、双方案比较、会签、定版方案。已定版版本被冻结，「生成新版本」不会覆盖原版本。
- **样品与记录**：登记样品、按类型/状态筛选、批次管理、状态摘要、实验关联、流转记录、ELN/LIMS 模拟来源摘要。
- **设备**：按名称/分类/业务状态筛选，查看能力、接入状态、共享范围、开放时段、使用条件、负责人、来源系统、运行数据摘要；可登记新设备摘要。
- **预约**：工作周切换，日历时段选择、时间冲突检查、维护设备阻断、人工提交、审批和取消；取消后时段释放，任务执行条件将重新检查。
- **实验管理**：状态筛选、搜索、负责人过滤、任务新建，以及概览/步骤/样品/设备/参数/记录/异常/数据/结果/关联记录 10 个页签。
- **上传数据**：表征分析页可下载 CSV 模板，再上传 CSV/TSV，保存真实文件中的数值数据并关联实验。
- **需求检查**：页脚开启后，点击页面功能或做空间导航打开右侧 PRD 抽屉。编辑并保存后可导出当前页面或完整 PRD；原始 Markdown 文件不被覆盖。

## 演示数据边界

- 所有业务动作在本浏览器通过 localStorage 保存，刷新保留；不需要后端、API 密钥或外部服务。
- AI 设计、预测、解释、审批人和设备运行数据均为演示逻辑，实际数值处理在前端执行。
- PDF/Word 附件登记文件名和大小，不解析二进制正文；Markdown/TXT/CSV 可读取文本。图像区可加载本地图像用于人工观察，不声称执行真实显微图像识别。
- ELN/LIMS/iLOMS 展示本地来源摘要，不接入真实系统，不启动设备或真实计算任务。
- 预约日期为固定演示排期，适合重复讲解流程。
- 进入首页后可在页脚「重置演示」恢复做空间示例。重置不删除读/算空间中已接收的下游草稿，也不重置 PRD 编辑文本。

## 验证方式

```powershell
pnpm exec tsx scripts/check-do-space.ts
pnpm exec tsc --noEmit
pnpm exec eslint src/components/do-space-v2 --max-warnings=0
pnpm build
```

浏览器回归脚本：`scripts/do-space-browser-flow.js`、`scripts/do-space-browser-results.js`、`scripts/do-space-browser-review.js`。它们通过 Playwright CLI 的 `run-code --filename=...` 依次执行，在独立浏览器演示会话中操作真实界面。
