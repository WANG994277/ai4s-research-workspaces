# 科研驾驶舱实现与验收记录

## 当前实现

- 科技态势：多源趋势、来源筛选、热点排行、机构统计与专题分布。
- 战略方向：方向排序、选中联动、多源证据、研判摘要与本机专家确认申请。
- 资源配置：算力、设备、人员分类，供需图、瓶颈列表、预测情景与协调记录。
- 项目监管：列表与详情、里程碑、关联任务/成果、风险与经费摘要。
- 科技成果：专题、搜索/分类/排序、详情、共享申请与项目跳转。

## 已验证

- 类型、lint、生产构建在驾驶舱实现阶段通过；五页业务区域检查通过。
- 48个有效路由与8个排除路由检查通过。
- 来源筛选、年份空状态/重置、图表数据表切换。
- 技术方向选中联动；专家确认申请保存后刷新恢复。
- 设备分类切换与资源协调记录创建。
- 项目选择、关联任务、风险记录与关联成果跳转至对应项目。
- 成果搜索空状态、共享申请保存后刷新恢复。
- 8个项目里程碑明细与列表汇总一致性检查。
- 桌面1672×941五页截图与1280宽度检查；结果保存在screenshots目录。

## 范围与剩余验证

- 原型只使用历史演示数据；生成的配图为示意资产。未接入真实检索、AI推理、设备监控、审批、SSO或外部系统。
- “导出汇总”导出顶部筛选范围全部分类，不应用页内搜索、页签或排序；JSON记录了此范围。
- 全局导航沿用现有项目，未将参考图的深色侧栏替换到全站。额外的局部导航和数据表入口导致纵向内容多于参考图。
- 最后一轮页面下半区截图遇到浏览器工具超时，完整视觉验收未收尾，详见根目录design-qa.md。
- 后续用户反馈的文献页签卡顿另行记录在progress.md；不能将驾驶舱的验证结果视为该问题已解决。
