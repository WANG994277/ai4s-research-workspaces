# 算空间演示指南

生产演示入口：`http://localhost:3002/compute-space?projectId=PROJ-SHALE-06`，本次已启动。

开发入口仍是 `http://localhost:3000/compute-space`（`pnpm dev`）。需要重新启动稳定演示时，运行 `pnpm build` 后运行 `pnpm start --port 3002`。不同端口的浏览器演示数据相互独立。

## 主流程（约 3 分钟）
1. 在顶部选择“深层页岩气储层机理研究”，进入“开始计算”。
2. 输入问题或使用示例，点击“开始计算”。在 Agent 三栏工作区点击“开始分析”。
3. 查看方案的输入数据版本、参数来源、计算方法、工具许可和资源；可修改方案或生成新版本。
4. 点击“创建计算任务”，勾选四项确认并提交。任务保存独立方案快照、参数、输入版本和确认记录。
5. 任务详情中点击“分配资源并运行”，再点击“推进计算演示”，最后“生成计算结果”。
6. 查看日志、7 类结果产物、分析、版本与追溯。结果可预览或下载，分析支持人工评价。
7. 点击“生成实验方案”，检查交接内容并确认，打开做空间中实际生成的实验方案草稿。

## 其他可演示流程
- **异常恢复**：任务中心打开“深层储层精细网格模拟”，查看失败原因，AI 异常解释，调整内存并确认重试。失败日志保留。
- **方案筛选**：选择地球科学、材料科学或合成生物，调整参数范围、约束和权重，生成候选、查看帕累托与对比。候选可转计算方案或实验草稿。
- **数据处理**：选择数据版本或导入 CSV/TSV，配置算子，创建处理任务，查看前后预览及质量报告，保存新版本，再回流方案或用于模型训练。处理中刷新可以恢复。
- **模型研发**：选择数据版本、算法、参数与资源，确认训练；训练刷新可恢复，生成新模型版本后使用固定测试集评价，进行多模型比较并确认发布。
- **科研工具**：搜索与收藏，查看八项详情；过期许可不可调用。管理侧可新建接入、填写 Schema/环境/许可、运行本地模拟调试并确认上架。
- **结果回流**：交接页“算 → 读”会创建研究任务并携带计算产物；“做 → 算”接受三列实测数据，保存预览及新数据版本，形成校准方案。
- **需求评审**：页尾“需求检视”模式可点击页面查看 PRD 映射。修改可在本机保存，支持当前页和含完整源文档的 Markdown 导出。正常演示时关闭检视。

## 状态与边界
- 计算、训练、评估、工具接口调试采用确定性 Mock 数据，不调用真实集群、AI 中台、许可证服务器或实验设备。
- 任务、方案、数据与模型版本、工具、交接和处理草稿保存在浏览器本地；同一浏览器刷新可恢复，换浏览器不会同步。
- CSV/TSV 保留元数据和前 6 条预览；处理算子及质量提升用于交互演示，不应作为生产清洗结果。
- 已创建任务保存独立方案快照。旧演示数据补快照时标注迁移记录，不能恢复此前未保存的历史内容。
- “重置演示”只清理算空间业务状态与处理草稿。已经交接到读/做空间的独立对象以及需求修订继续保留。
- P2 优化能力通过参数空间、多目标筛选、同类结果比较、敏感性和资源配置演示；无真实大规模调度优化服务。

```powershell
node --import tsx scripts/check-compute-space.ts
node --import tsx scripts/check-compute-prd.ts
node --import tsx scripts/check-compute-handoff.ts

pnpm run lint:build
pnpm build
```
