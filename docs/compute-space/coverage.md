## P0：科研问题到结果验证

- [ ] 首页可输入问题、引用课题/假设/读空间结论/数据/模型/工具/结果/实验数据，上传文件并进入 Agent。
- [ ] 八类快捷任务、单一计算 Agent、五个专业工作台和最近任务入口可用。
- [ ] Compute Context 的课题、目标、证据和版本引用跨页保留。
- [ ] Agent 三栏展示上下文、八步任务计划、阶段结论与结构化方案；运行日志位于任务详情。
- [ ] 方案具备目标、方法、输入、变量/固定参数、范围、版本、工具、资源、输出/评价指标、风险和来源。
- [ ] 编辑/保存/新版本/依据可用；参数区分文献、实验、领域默认、AI 建议和人工输入来源。
- [ ] 正式任务、大批量组合、方法与高成本资源/许可需要确认，确认记录可追溯。
- [ ] 任务生命周期覆盖草稿、待确认、待提交、排队、运行、结果生成、完成，以及暂停、失败、取消、资源不足和等待处理。
- [ ] 任务中心可检索筛选；停止、重试、克隆、重跑、新版本、下载与分析动作更新真实本地状态。
- [ ] 详情八个视图显示配置、参数、输入、资源、运行、日志、结果、分析和追溯。
- [ ] 参数可查看原方案值/实际值/来源/修改记录；日志可搜索、筛选 Error/Warning、下载。
- [ ] 失败显示阶段、原因、影响和建议；可 AI 解释、修改后重试和克隆。
- [ ] 结果可预览、下载、保存 Artifact，并保留主要结果、敏感参数、最优区间、异常和下一步。
- [ ] 结论区分待人工分析、人工确认、与实验一致/有偏差、进一步验证，不把 AI 解释当作最终结论。
- [ ] 科研工具可浏览并看到分类、版本、许可、环境、输入输出和可用状态。
- [ ] 读→算传递假设/证据/参数；算→做确认后实际携带实验草稿；算→读带入冲突和待补充问题；做→算可校准/重训/重算。
- [ ] 刷新后可恢复新方案、任务、版本和结果；无效 ID、空态与加载失败有可理解反馈。

## P1：五个专业工作台完整流程

- [ ] 设计工作台可配置三类场景、目标、约束、参数范围、权重和插件。
- [ ] 候选表格/图表/帕累托可查看，约束淘汰与排序随配置变化；候选可比较、查看参数/依据并转计算或实验方案。
- [ ] 数据处理可选版本、配置清洗/转换/缺失/异常/标准化/特征/算子并创建任务。
- [ ] 处理结果可前后预览和质量检查，形成保留上游/流程/人员/时间的新版本并回流任务。
- [ ] 训练绑定数据版本、模型、参数和资源；确认后运行，形成模型版本和训练追溯。
- [ ] 固定测试集评价、多模型/版本/测试集比较、误差分析与评价 Artifact 可用。
- [ ] 科学评价涵盖物理约束、机理、误差、外推范围和专业指标；模型发布需确认。
- [ ] 多任务分析可选择任务，对比参数/曲线/指标，查看敏感性、误差、异常、实验偏差与 AI 解释。
- [ ] 工具详情八类信息可查看；收藏、加入方案、Agent 调用和正式任务确认流程完整。
- [ ] 管理侧可新接入 CLI/API/Python/容器/HPC/仿真/模型服务，配置 Schema、环境、版本、许可、权限、资源、超时和回传方式。
- [ ] 工具调试、失败反馈、发布、上架、下架会同步到广场。

## P2：可演示扩展点

- [ ] 跨任务优化：从多个结果形成新方案建议，保留来源。
- [ ] 大规模参数搜索：配置范围/规模/预算，确认后演示批量生成与排序。
- [ ] 自动实验设计：把推荐参数转为可编辑实验草稿，人工确认后流转。
- [ ] 高级敏感性：切换分析方法并展示贡献度、排序和科学边界。
- [ ] 多模型自动比较：固定测试集批量评价并说明推荐依据。
- [ ] 资源优化：比较成本、时间和资源策略，并可应用到待确认任务。

## 需求检视与导出

- [ ] 默认模式下按钮、菜单、Tab、输入和任务运行行为不被检视器拦截。
- [ ] 打开“需求检视”后，点击/Enter/Space 可打开右侧抽屉；未单独标注区域回退当前页章节。
- [ ] `data-prd-id` 支持逗号或空格分隔多 ID，全部 ID 能在映射中解析。
- [ ] 抽屉显示来源、用户故事、描述、验收条件、规则、状态、假设及关联区域；支持键盘关闭和焦点管理。
- [ ] 编辑后立即更新当前映射并自动本地保存；显式“保存 PRD”可用且有状态反馈；刷新可恢复。
- [ ] 当前页 Markdown 仅包含该页结构和关联需求；导出包括最新本机修订。
- [ ] 完整 Markdown 包含所有页面映射、设计系统、最新修订及完整来源 PRD 第 0～33 章。
- [ ] 原文读取失败时不生成伪完整导出，界面允许重试；导出不改写桌面原始文件。

## 建议演示顺序

1. 首页引用读空间结论 → Agent 编辑方案 → 人工确认 → 创建任务。
2. 任务运行/日志 → 模拟完成 → 结果分析 → 确认实验交接。
3. 失败任务 → AI 分析 → 修改后重试 → 对比两次结果。
4. 智能设计候选筛选 → 数据处理新版本 → 模型训练和科学评价。
5. 工具新接入 → 调试/发布 → 广场使用并加入计算方案。
6. 需求检视 → 编辑并保存 → 刷新恢复 → 当前页/完整 PRD 导出。
