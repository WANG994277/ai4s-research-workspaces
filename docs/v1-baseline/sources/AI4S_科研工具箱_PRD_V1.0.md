# AI4S 科研工具箱 PRD V1.0

> 版本：V1.0  
> 产品名称：AI4S 科研平台  
> 模块名称：科研工具箱  
> 适用角色：科研人员、项目/课题负责人；分析化验人员按授权使用部分工具；平台管理员负责工具接入与治理  
> 设计基线：科研工具箱用于统一承载科研软件、专业科研工具、MCP 服务、插件/连接器、数据处理与科学计算工具等可调用能力；科研技能和科研模型已作为独立一级模块，不在工具箱中重复建设。  
> 本文档用途：作为原型、UI、前端、后端、权限、工具接入、Research Agent 调用和测试设计的统一开发基线。

---

# 一、产品定位

科研工具箱是 AI4S 面向科研人员的科研工具发现与调用入口。

其核心目标是解决：

1. **平台接入了哪些科研工具？**
2. **某个工具适合完成什么科研任务？**
3. **当前用户是否具备使用条件和权限？**
4. **如何直接使用工具，或将工具交给 Unified Research Agent 调用？**

科研工具箱不承担 Skill、科研模型、科研资产的重复展示和管理。

# 三、核心产品原则

## 3.1 前台按科研用途组织，不按技术协议组织

科研人员看到的是：

```text
通用
地球科学
材料科学
合成生物科学
其他
```

以及：

```text
数据处理
科学计算
专业软件
科研辅助
外部服务
```

而不是首先看到：

```text
MCP
API
Plugin
REST
WebSocket
Connector
```

技术接入类型只作为详情标签或后台管理属性。

---

## 3.2 Research Agent 默认可自动调用工具

用户通常不需要：

> 先找工具 → 再进入任务。

更典型的方式是：

```text
用户提出科研任务
↓
Research Agent 自动判断
↓
调用合适工具
↓
返回结果
```

科研工具箱主要服务于：

- 主动发现工具；
- 高级用户指定工具；
- 查看工具能力；
- 直接打开科研软件；
- 配置必要连接；
- 将工具加入当前 Research Task。

---

## 3.3 工具箱不是应用商店

V1.0 不建设复杂：

- 评分体系；
- 社区评论；
- 排行榜；
- 商业购买；
- 复杂订阅市场。

重点是：

> **发现 → 了解 → 使用 → 加入科研任务。**

# 十二、专业科研工具

用于承载粒度小于完整软件、但又不是 Skill 的专业能力。

- 光谱分析；
- 科研图表处理；
- 结构可视化；
- 文件解析；
- 单位转换；
- 专业数据预处理。

---

## 12.1 与 Skill 的边界

科研工具强调：

> **明确、稳定、可执行的工具能力。**

Skill 更强调：

> **面向任务的标准化能力封装。**

例如：

```text
PDF解析器
→ 工具

从20篇论文提取实验条件并结构化整理
→ Skill
```

# 二十六、Research Agent 调用要求

Agent 调用 Tool 前必须校验：

1. 用户是否有工具权限；
2. 当前 Space 是否有权限；
3. 依赖数据是否有权限；
4. 外部连接是否有效；
5. 软件许可证是否有效；
6. 当前工具是否在线。

Research Agent 不得绕过任何授权限制。

# 四十、核心验收标准

## 40.1 工具箱

- [ ] 科研技能和科研模型不在工具箱重复展示；
- [ ] 支持通用、地球科学、合成生物科学、材料科学、其他分类；
- [ ] 支持工具搜索；
- [ ] 支持工具类型筛选；
- [ ] 不以 MCP / API / Plugin 作为主要前台分类。

---

## 40.2 工具详情

- [ ] 明确说明工具能做什么；
- [ ] 明确说明输入；
- [ ] 明确说明输出；
- [ ] 明确说明使用条件；
- [ ] 明确说明当前授权和可用状态。

---

## 40.3 调用

- [ ] 支持直接使用；
- [ ] 支持打开科研软件；
- [ ] 支持加入 Research Agent；
- [ ] 支持加入当前 Research Task；
- [ ] Agent 可自动调用工具；
- [ ] 调用前完成权限和依赖校验。

---

## 40.4 长任务

- [ ] 即时工具不制造额外任务卡片；
- [ ] 长周期工具任务自动进入当前 Research Task；
- [ ] 支持后台执行；
- [ ] 支持等待资源；
- [ ] 支持状态恢复。

---

## 40.5 权限

- [ ] Project / Space 权限有效；
- [ ] 外部系统授权有效；
- [ ] 无权限工具不得调用；
- [ ] Agent 不得绕过工具 ACL；
- [ ] 工具依赖数据权限同步校验。

# 四十一、最终产品基线

科研工具箱最终定义为：

> **AI4S 中面向科研人员的科研工具发现与调用入口，统一承载科研软件、专业科研工具、数据处理、科学计算、MCP 服务及插件/连接器等能力，并按照科研学科和科研用途进行组织；科研人员既可以直接使用工具，也可以将工具加入 Unified Research Agent 或当前 Research Task，由 Agent 自动完成后续调度。**

模块核心链路统一为：

> **发现工具 → 了解能力 → 获得授权 → 使用 / 调用 → 进入科研任务 → 形成科研结果。**
