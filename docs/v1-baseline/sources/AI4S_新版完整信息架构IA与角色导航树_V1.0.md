# 2. 全平台 IA 核心原则

## 2.1 一级模块名称保持不变

```text
AI4S
├─ 科研工作台
├─ 知识中心
├─ 科研技能
├─ 科研模型
├─ 科研工具箱
├─ 云上实验室
├─ 科研资产
├─ 项目空间管理
├─ 科研管理工作台
├─ 科研决策工作台 / 科研驾驶舱
├─ 科研项目管理【集成】
└─ 平台管理后台
```

不得自行新增：

- 读空间；
- 算空间；
- 做空间；
- Agent 广场；
- 数据集广场；
- 实验方案中心；
- 样品管理；
- 分析化验独立门户；
- 自动化实验工作流；
- 独立任务中心；
- 其他未在 V1.0 基线确认的一级模块。

## 2.2 Unified Research Agent 是科研执行主入口

科研工作台以 Unified Research Agent 为唯一主入口。“读、算、做”不再作为前台一级空间或独立 Main Agent 展示。Knowledge、Skill、Model、Tool、Software、Dataset、Experiment 等作为 Research Agent 可调用资源或业务对象存在。

## 2.3 Project 定义项目边界，Space 定义上下文与权限范围

```text
Project
├─ Project Space
└─ Topic Space × N

User
└─ Personal Space
```

全平台业务页面不得自行创建另一套“项目上下文”或“课题上下文”。

## 2.4 一级导航与页面路由分离

以下内容不自动成为左侧一级/二级导航：

- 详情页；
- 搜索结果页；
- 创建页；
- 编辑页；
- 试用页；
- 执行页；
- 失败态；
- 权限受限态；
- Bottom Sheet / Drawer / Dialog；
- 任务运行状态；
- Agent 执行轨迹。

## 2.5 角色可见性与对象权限分离

导航可见不等于对象可访问。最终权限统一由：

```text
System Role
∩ Project Membership
∩ Space Membership / Space Role
∩ Object / Asset ACL
```

共同决定。

# 5. 各一级模块完整 IA

## 5.1 科研工作台

```text
科研工作台
├─ 工作台首页
│  ├─ Unified Research Agent 主入口
│  ├─ 需要我处理
│  ├─ 当前研究
│  └─ 最近科研产出
├─ 当前会话 / Research Agent 会话页
├─ 当前研究列表
├─ Research Task 详情
├─ 最近科研产出列表
└─ 历史会话
```

不作为固定二级导航：Human Decision Bottom Sheet、调用能力选择器、科研上下文选择器、Agent 执行轨迹详情、保存为科研资产弹窗、任务失败态、任务恢复态。

历史会话优先作为科研工作台左侧会话栏，而非平台级独立模块。

## 5.2 知识中心

固定导航尽量收敛为：

```text
知识中心
├─ 首页 / 一站式检索
├─ 知识库
└─ 知识图谱
```

模块内路由：

```text
检索结果
├─ 全部
├─ 文献
├─ 专利
├─ 标准
├─ 内部资料
└─ 数据集

详情
├─ 文献详情
├─ 专利详情
├─ 标准详情
├─ 内部资料详情
└─ 数据集详情
```

首页必须保留：智能检索、关键词检索、高级检索、分子结构式检索。

## 5.3 科研技能

```text
科研技能
└─ Skill 广场
```

页面状态：Skill 搜索结果、Skill 详情、Skill 试用、版本信息、权限受限、创建 Skill 跳转 AI 中台、加入 Research Agent、加入当前 Research Task。

不新增“我的 Skill”独立管理模块；正式资产进入科研资产。

## 5.4 科研模型

```text
科研模型
└─ 模型广场
```

页面状态：模型搜索结果、模型详情、模型试用、输入配置、运行状态、运行结果、版本、权限受限、创建模型跳转 AI 中台、加入 Research Agent、加入当前 Research Task。

不新增“我的模型”独立管理模块；正式资产进入科研资产。

## 5.5 科研工具箱

```text
科研工具箱
└─ 工具广场
```

按科研用途筛选：科研软件、专业科研工具、数据处理、科学计算、可视化、文件处理、外部服务、连接器、其他。

页面路由：工具搜索结果、工具详情、科研软件详情、工具直接使用、软件启动、外部连接授权、运行结果、长任务等待、失败 / 不可用。

MCP / Plugin / Connector 不作为科研人员核心一级分类。

## 5.6 云上实验室

固定四个二级功能：

```text
云上实验室
├─ 仪器设备纳管
├─ 仪器设备共享
├─ 实验任务管理
└─ 实验试剂耗材管理
```

### 仪器设备纳管

设备列表、设备详情、新增设备、编辑设备、接入与状态。

### 仪器设备共享

共享设备广场、共享设备详情、设备预约、我的预约、预约详情、使用记录。

### 实验任务管理

实验任务列表、创建实验任务、实验任务详情、实验执行、实验异常、实验结果提交、实验结果详情。

### 实验试剂耗材管理

试剂耗材列表、试剂耗材详情、领用 / 消耗登记、库存预警。

严格不增加样品管理、实验方案中心、分析化验独立门户、自动化实验编排、实验室安全管理、采购供应链。

## 5.7 科研资产

固定二级结构：

```text
科研资产
├─ 我的资产
└─ 项目资产
```

资产类型：全部、智能体、Skill、模型、数据集、方案模板。

项目资产内部通过筛选区分：当前课题、项目公共、其他课题授权共享。不再为资产类型创建新的一级模块。

## 5.8 项目空间管理

固定二级结构：

```text
项目空间管理
├─ 项目空间
├─ 课题空间
├─ 空间成员
├─ 角色与权限
└─ 空间配置
```

仅管理 Project / Space、Membership、Space Role、Permission、Space 状态、AI 中台资源空间映射，不承担传统科研项目全生命周期管理。

## 5.9 科研管理工作台

```text
科研管理工作台
├─ 管理概览
├─ 项目运行
├─ 科研进展
├─ 风险与异常
└─ 科研成果
```

仅使用既有 Project、Research Task、Experiment Task、Research Asset、Space 状态及外部科研项目管理系统同步信息；不配置 Project / Space ACL；不默认访问私人 Agent Session。

## 5.10 科研决策工作台 / 科研驾驶舱

```text
科研决策工作台 / 科研驾驶舱
├─ 科研态势
├─ 重大项目
├─ 风险与异常
├─ 科研成果
└─ 科研资源
```

可在科研态势或资源视图中聚合团队/专业结构，但不建设独立人力资源系统。

不承担项目日常编辑、Space 成员配置、科研资产删除、平台配置。

## 5.11 科研项目管理【集成】

```text
科研项目管理【集成】
└─ 外部科研项目管理系统入口
```

AI4S 不重复建设申报、立项、经费、合同、中期检查、验收和完整项目生命周期。

## 5.12 平台管理后台

仅平台管理员可进入，继续承载用户与系统角色、Project / Space 全局治理、权限规则、科研资源接入、系统集成、平台运维、科研资产治理、资源上下架和异常处理。

系统管理权不等于科研内容业务查看权。

# 7. 多角色叠加后的导航规则

1. 多角色导航按允许功能并集合并；
2. 同一模块只显示一次，不按角色复制入口；
3. 对象级显式拒绝、空间隔离和数据范围限制优先；
4. 即使一级模块可见，仍需校验 Project Membership、Space Membership、数据范围、Object ACL、外部系统授权。

# 11. 原型必须体现的 IA 约束

1. 全平台只保留一个 Unified Research Agent 主入口；
2. 不出现读 / 算 / 做三个独立一级空间；
3. Space 切换器全局统一；
4. 同一业务对象不在多个模块重复创建；
5. Skill / Model 广场与科研资产使用同一底层对象；
6. 科研资产固定为“我的资产 / 项目资产”两大视图；
7. 云上实验室固定四个二级功能；
8. 项目空间管理固定五个二级功能；
9. 科研管理工作台与科研决策工作台采用不同角色视角，不复制科研工作台；
10. 外部科研项目管理明确标识“集成”；
11. 私人 Agent Session 不因进入项目/管理视图而自动开放；
12. 无权限对象不得通过导航、搜索、聚合统计泄露敏感内容。

# 12. 最终 IA 基线

AI4S V1.0 前台统一采用：

> **一个科研执行主入口 + 科研知识/能力/实验资源入口 + 科研资产 + 空间治理 + 科研管理工作台 + 科研决策驾驶舱 + 外部科研项目管理集成 + 平台管理后台。**

后续所有 PRD、原型和研发路由均以本 IA 为入口层级基线。
