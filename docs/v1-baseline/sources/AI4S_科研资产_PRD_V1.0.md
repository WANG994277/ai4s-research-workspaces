# AI4S 科研资产 PRD V1.0

> 版本：V1.0  
> 产品名称：AI4S 科研平台  
> 模块名称：科研资产  
> 适用角色：科研人员、项目/课题负责人、科研项目管理人员、科研管理人员、科研决策人员、平台管理员（按角色和数据范围授权）  
> 设计基线：科研资产用于统一管理科研过程中形成并沉淀的个人资产和项目资产；资产类型包括智能体、Skill、模型、数据集、方案模板等。智能体、Skill、模型、数据集的创建能力复用 AI 中台，AI4S 负责入口、上下文传递、资产回流、权限、共享和使用。  
> 本文档用途：作为原型、UI、前端、后端、权限、资产生命周期、AI 中台集成和测试设计的统一开发基线。

---

# 一、产品定位

科研资产用于回答两个核心问题：

1. **我个人沉淀了哪些可以继续使用的科研资产？**
2. **当前项目 / 课题已经形成了哪些可以共享和复用的科研资产？**

科研资产不是“广场”。

其核心定位是：

> **拥有、管理、版本、共享和复用。**

与其他模块的边界：

```text
科研技能 / 科研模型
= 发现和调用平台已发布资源

科研资产
= 管理我和当前项目拥有的资产
```

# 四、核心产品原则

## 4.1 我的资产和项目资产是同一资产模型的不同视图

不建立两套独立资产数据。

统一使用：

```text
Research Asset
```

通过以下属性决定展示位置：

```text
owner_id
project_id
space_id
visibility
asset_type
```

---

## 4.2 过程产物不自动等于正式资产

Research Agent 执行过程中可以产生大量中间结果。

只有经过：

> 保存 / 确认 / 沉淀

以后，才进入科研资产。

统一生命周期：

```text
Research Artifact
↓
保存 / 确认
↓
Research Asset
↓
版本 / 分享 / 发布
↓
被其他用户或 Agent 复用
```

---

## 4.3 资产所属与资产可见范围分离

一个资产可以属于某个个人或 Space，但通过授权共享给其他空间。

例如：

```text
课题 A 数据集
所属：课题 A
共享：课题 B 可引用
```

不因为共享就改变资产归属。

---

## 4.4 Project ID 是项目资产聚合主索引

项目资产查询以：

```text
project_id
```

为核心。

在此基础上再结合：

- space_id；
- owner_id；
- Asset ACL；

确定用户最终可见范围。

# 五、目标用户

## 5.1 科研人员

主要需求：

- 查看我的资产；
- 查看当前项目有权访问的资产；
- 将科研产出沉淀为资产；
- 创建智能体 / Skill / 模型 / 数据集；
- 调用资产；
- 分享个人资产；
- 将资产加入 Research Agent；
- 查看资产版本。

---

## 5.2 项目/课题负责人

在科研人员基础上进一步关注：

- 当前课题资产；
- 项目公共资产；
- 跨课题共享资产；
- 项目资产共享；
- 资产发布和复用情况。

---

## 5.3 科研项目管理人员

重点关注：

- 项目资产范围；
- Space 与资产关系；
- 项目内共享权限；
- 必要的资产治理。

不默认编辑科研人员私人资产内容。

---

## 5.4 科研管理 / 决策人员

主要以查看为主。

根据授权查看：

- 项目科研资产；
- 关键成果资产；
- 已发布或共享的资产。

不默认获得个人私有资产编辑权。

---

## 5.5 平台管理员

负责：

- 资产类型配置；
- 发布治理；
- 异常资产处理；
- 平台级权限规则；
- 系统同步和状态治理。

系统管理权不等于科研内容业务查看权。

# 九、项目资产

## 9.1 定义

项目资产指：

> **当前 Project ID 下，用户有权访问的科研资产集合。**

不是所有项目成员自动看到所有资产。

---

## 9.2 数据范围

项目资产由三类内容组成：

```text
1. 当前课题资产
2. 项目公共资产
3. 其他课题授权共享资产
```

---

## 9.3 查询原则

示意：

```text
project_id = current_project
AND
(
    space_id IN accessible_spaces
    OR visibility = PROJECT
    OR asset_id IN authorized_assets
)
```

# 十、当前课题资产

当前 Space 为 Topic Space 时，优先展示：

> 当前课题直接拥有或沉淀的资产。

包括：

- 课题成员沉淀至课题的资产；
- Research Task 产生并保存至课题的资产；
- AI 中台创建并回流当前课题的资产。

---

# 十一、项目公共资产

项目公共资产用于：

> 项目内部可共同发现、引用和复用的正式资产。

将资产设为项目公共需要满足相应权限。

普通科研人员不能默认把任意私人资产直接变成项目公共资产。

---

# 十二、其他课题授权共享资产

同一 Project ID 下，课题之间默认隔离。

只有经过明确共享后，其他课题才可访问。

例如：

```text
Project P001
├─ 课题 A
│   └─ 数据集 A
└─ 课题 B
```

课题 A 执行：

```text
共享数据集 A → 课题 B
```

课题 B 才能在：

> 项目资产 → 其他课题授权共享

中看到该资产。

# 三十、分享权限级别

至少支持：

```text
只读
可引用
可复制
可协作
```

含义：

### 只读

可以查看，不可直接用于 Agent 或复制。

### 可引用

可作为 Research Agent / Research Task 上下文使用。

### 可复制

可复制为自己的 / 本空间资产副本。

### 可协作

可参与编辑或维护，具体能力根据资产类型控制。

# 四十四、我的资产权限

默认：

| 操作 | 所有者本人 | 其他用户 |
|---|---:|---:|
| 查看 | ✓ | 默认 × |
| 编辑 | ✓ | × |
| 删除 / 归档 | ✓ | × |
| 版本管理 | ✓ | × |
| 分享 | ✓ | × |
| 申请发布 | ✓ | × |

获得明确授权的协作者除外。

---

# 四十五、项目资产权限

普通科研人员：

- 查看本人所在 Space 的资产；
- 查看项目公共资产；
- 查看明确共享给本人 / 当前 Space 的资产。

项目/课题负责人：

- 查看所负责范围资产；
- 按权限分享；
- 按权限确认或申请发布。

科研项目管理人员：

- 管理项目范围共享和空间关系；
- 不默认编辑科研内容本身。

平台管理员：

- 管理平台级资产状态和治理规则；
- 不默认阅读无业务授权的私人科研内容。

---

# 四十六、权限来源展示

资产详情建议能够显示：

```text
当前权限：可引用
来源：页岩气储层评价课题共享
```

避免用户不知道为什么“能看但不能编辑”。

# 五十七、核心验收标准

## 57.1 信息架构

- [ ] 科研资产一级仅重点区分“我的资产 / 项目资产”；
- [ ] 支持智能体、Skill、模型、数据集、方案模板；
- [ ] 项目资产可区分当前课题、项目公共、授权共享；
- [ ] 不与科研技能广场、科研模型广场重复建设。

---

## 57.2 创建

- [ ] 支持新建智能体；
- [ ] 支持新建 Skill；
- [ ] 支持新建模型；
- [ ] 支持新建数据集；
- [ ] 上述创建能力跳转 AI 中台；
- [ ] 创建完成后可回流 AI4S 并自动登记资产。

---

## 57.3 科研产出沉淀

- [ ] Research Artifact 可保存为 Research Asset；
- [ ] 可选择我的资产 / 当前课题资产 / 项目公共资产；
- [ ] 自动继承 Task / Session / Space 等来源信息；
- [ ] 普通 Agent 回复不自动形成正式资产。

---

## 57.4 项目资产

- [ ] 按 Project ID 聚合；
- [ ] 按 Space 和 ACL 过滤；
- [ ] 不同课题默认隔离；
- [ ] 支持跨课题授权共享；
- [ ] 分享不改变原资产归属。

---

## 57.5 分享

- [ ] 支持项目空间；
- [ ] 支持指定课题；
- [ ] 支持指定成员；
- [ ] 支持只读 / 可引用 / 可复制 / 可协作；
- [ ] 支持有效期；
- [ ] 支持取消共享。

---

## 57.6 发布

- [ ] 分享和发布概念分离；
- [ ] Skill 发布后可进入科研技能广场；
- [ ] 模型发布后可进入科研模型广场；
- [ ] 未发布资产仍可作为私人 / 项目资产存在；
- [ ] 发布过程可审核和追溯。

---

## 57.7 权限

- [ ] System Role / Project / Space / Asset ACL 联合生效；
- [ ] 我的资产默认私有；
- [ ] 项目成员不能默认查看其他成员全部私人资产；
- [ ] 无权限资产不会通过搜索泄露；
- [ ] Research Agent 不得绕过 Asset ACL。

---

# 五十八、最终产品基线

科研资产最终定义为：

> **AI4S 中统一管理个人和项目科研资产的核心模块，通过“我的资产”和“项目资产”两类视图管理智能体、Skill、模型、数据集、方案模板等正式科研资产，并通过 Project ID、Space 和 Asset ACL 实现项目内跨课题的可控共享；科研过程产出经过确认后可以沉淀为资产，智能体、Skill、模型和数据集的创建能力复用 AI 中台，资产发布后可进一步进入科研技能、科研模型等平台资源发现体系。**

核心链路统一为：

> **科研任务产生结果 → 沉淀资产 → 版本管理 → 项目 / 课题共享 → 正式发布 → 被科研人员与 Research Agent 再次复用。**
