# AI4S V1.0 最终PRD审查矩阵

审查基线：`docs/v1-baseline/sources/` 中15份V1.0文档、角色权限矩阵、对象模型，以及用户在2026-09-24追加的导航与科研项目管理要求。

状态定义：

- **原型通过**：页面、状态、操作与本地数据闭环已实现，可在浏览器验证。
- **只读集成通过**：AI4S按要求展示来源系统信息和跳转边界，不在本平台重建外部流程。
- **真实接入待实施**：前端原型具备入口、状态与参数边界，但正式AI、数据库、设备或外部系统尚未连接。

## 公共交互与权限

- 统一SpaceSwitcher；切换后重算数据，不迁移原对象；未提交表单提示确认。
- 搜索和资源选择在返回前过滤权限；写操作在提交时再次校验。
- 统一状态词、StatusBadge、PermissionBadge含义、空态、Loading、错误、受限态、确认弹窗、Toast和来源/版本视图。
- 页面正文不显示内部ID；项目与空间内部ID仅作为本地数据键。
- 全部真实外部连接保持“未配置/模拟/最后同步时间”说明，不伪装为生产能力。
