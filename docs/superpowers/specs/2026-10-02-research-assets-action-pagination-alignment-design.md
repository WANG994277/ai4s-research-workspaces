# 科研资产操作列表头与按钮对齐设计

## 目标

统一科研资产列表操作列的视觉基准：“操作”表头与下方各行操作按钮在同一中心线上。

## 范围

- 仅调整科研资产列表的布局样式。
- “操作”表头与各行操作按钮保持同一中心线。
- 不修改列内容、列顺序、数据筛选、翻页逻辑、分页布局或响应式断点。

## 实现设计

保留操作列现有固定宽度和表头居中方式，将科研资产主题下行内操作容器从左对齐改为居中对齐。修改限定在科研资产模块的 CSS 选择器内，避免影响空间管理等其他列表。

## 验收标准

1. “操作”表头和每行“查看”等操作在操作列中水平居中并同轴。
2. 单个操作和多个操作都作为整体在操作列中居中。
3. 项目资产、我的资产两种表格视图均满足上述要求。
4. 窄屏横向滚动行为与现有实现一致。
5. 现有构建与科研资产页面检查脚本通过。

## 非目标

- 不重设表格各业务列宽。
- 不改造分页组件、分页布局或交互。
