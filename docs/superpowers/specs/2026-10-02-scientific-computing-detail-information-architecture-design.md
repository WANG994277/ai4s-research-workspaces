# 科学计算任务详情信息架构设计

## 目标

消除“概览、运行过程、计算结果、结果文件、运行日志”之间的重复和内容堆叠，使每类信息只有一个完整归属。

## 页签结构

- `概览`：状态、关键结果、可信性提示和下一步入口，只保留摘要。
- `配置与运行`：输入、计算参数、运行环境、子任务进度和运行时间线。
- `结果分析`：收敛曲线、参数扫描结果、推荐参数和分析说明。
- `文件与日志`：输入/输出文件、配置文件与完整运行日志。

旧查询参数继续可用，并映射到新页签：`运行过程 → 配置与运行`、`计算结果 → 结果分析`、`结果文件/运行日志 → 文件与日志`。

## 去重规则

- 同一信息只在一个页签完整展示。
- 概览只显示摘要和跳转按钮，不复制完整图表、表格、文件列表或日志。
- 计算摘要归属“配置与运行”。
- 参数扫描和收敛曲线归属“结果分析”。
- 文件和日志归属“文件与日志”。

## 验证

- 领域测试保护四页签及旧链接映射。
- 类型检查和构建检查组件分支完整性。
- 浏览器分别检查运行中和已完成任务的四个页签。
