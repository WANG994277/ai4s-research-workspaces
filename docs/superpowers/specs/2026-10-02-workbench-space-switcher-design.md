# 科研工作台空间切换优化设计

## 目标

优化科研工作台首页的空间切换入口与弹窗层级，使用户可以在个人空间、全部空间、项目空间和子课题空间之间进行演示性切换，并将顶部“当前课题”统一改为“当前空间”。

## 范围

- 修改科研工作台首页右上角空间切换入口文案与当前选中名称。
- 优化“切换科研空间”弹窗的内容层级和视觉样式。
- 增加“个人空间”和“全部空间”两个可选择入口。
- 在“全部空间”下展示项目空间，并在项目空间下展示对应子课题空间。
- 本期切换仅影响界面中的当前空间名称与选中态，不关联首页统计、任务、推荐或其他业务数据。

## 信息架构

弹窗空间树采用以下固定层级：

```text
个人空间
全部空间
├─ 项目空间 A
│  ├─ 子课题空间 A1
│  └─ 子课题空间 A2
└─ 项目空间 B
   └─ 子课题空间 B1
```

“个人空间”“全部空间”“项目空间”和“子课题空间”均可独立选择。项目空间负责展开或收起其子课题，同时保留独立的切换操作，避免展开动作与空间选择冲突。

## 交互设计

1. 顶部入口统一显示“当前空间：{空间名称}”。
2. 点击入口打开空间切换弹窗，并自动呈现当前选中空间。
3. 点击个人空间或全部空间后，立即更新顶部名称和弹窗选中态并关闭弹窗。
4. 点击项目空间的展开控制可查看子课题；点击项目空间主体可切换至该项目空间。
5. 点击子课题空间可切换至对应子课题。
6. 搜索保留现有能力，仅匹配真实项目空间和子课题空间；个人空间、全部空间始终显示。
7. 若当前页面存在未提交内容，沿用现有二次确认逻辑。

## 状态边界

- “个人空间”和“全部空间”是前端演示用虚拟选择项，不写入既有科研空间数据模型。
- 虚拟选择项只更新 Shell 层当前展示状态。
- 真实项目空间和子课题空间继续使用现有 `spaceId` 切换逻辑。
- 页面刷新后可回到既有真实空间；本期不要求持久化虚拟选择项。
- 不修改权限、数据范围、路由或首页内容聚合逻辑。

## 视觉设计

- 弹窗维持居中宽弹窗形态，强化标题、搜索区、快捷空间区和空间树之间的分区。
- 个人空间与全部空间采用同一层级的快捷选择卡片，具有图标、名称和辅助说明。
- 项目空间采用清晰的父级行，子课题缩进并使用连接线表达归属关系。
- 选中项使用浅蓝背景、蓝色文字和勾选图标；悬停态不改变布局尺寸。
- 保证交互目标不小于 44px，并保留键盘焦点样式和 `aria-expanded` 等可访问性语义。

## 验收标准

- 科研工作台首页右上角不再出现“当前课题”，统一为“当前空间”。
- 弹窗可见并可选择个人空间和全部空间。
- 全部空间下按“项目空间 → 子课题空间”展示现有数据。
- 四类空间切换后，顶部名称和弹窗选中态正确同步。
- 切换个人空间或全部空间不会改变首页业务数据。
- 项目展开、搜索、关闭弹窗和未保存内容确认行为保持可用。
