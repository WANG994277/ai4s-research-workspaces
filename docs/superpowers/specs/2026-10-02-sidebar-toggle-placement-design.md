# 左侧导航折叠按钮位置调整设计

## 目标

将现有左侧导航底部的展开/收起按钮迁移到页面顶部栏左端、“当前页面”信息之前，提升入口可发现性，同时保持现有导航结构和交互行为。

## 范围

- 修改全局壳层组件 `src/components/v1/shell.tsx`，复用既有顶部栏样式。
- 删除侧栏底部原有折叠控制区域。
- 在顶部栏“当前页面”信息之前增加同一折叠控制按钮。
- 不修改科研超级中枢、科研任务模块、原型提取逻辑或无 iframe 架构。

## 交互与视觉

- 展开状态下，按钮显示向左箭头，`aria-label` 与 `title` 为“收起导航”。
- 收起状态下，按钮显示向右箭头，`aria-label` 与 `title` 为“展开导航”。
- 按钮沿用顶部栏现有的 30px 方形 `v-top-nav-toggle` 样式，与“当前页面”文字保持 8px 间距。
- 延续现有中性色与悬停背景，并提供清晰的键盘焦点样式。
- 保留现有 226px/72px 宽度和折叠状态逻辑。

## 组件与状态

不新增状态或组件。按钮继续使用 `BaselineShell` 的 `collapsed` 状态和 `setCollapsed` 更新函数。

## 验证

- 自动化测试确认按钮位于顶部栏“当前页面”信息之前，且侧栏 Logo 区没有新增折叠按钮。
- TypeScript 与 ESLint 校验通过。
- 在 `localhost:3000` 手动确认展开和收起状态下按钮均可见、可点击，导航宽度和内容布局正常。
