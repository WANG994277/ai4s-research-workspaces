# 算空间 PRD V1.0 重构实施计划

依据：用户提供的 AI4S_算空间_PRD_V1.0.md。参考图仅用于结构参考，冲突时采用 PRD。用户已要求完整实现并允许 mock，不增加设计审批步骤。

## 设计与边界
- 复用现有 Next.js、React、Lucide、Recharts、Radix 组件和 AI4S 设计系统。
- 白色工作区、深灰文本、朱丹红关键确认；桌面紧凑三栏 Agent、表格任务中心、配置/预览专业工作台。
- 方案与任务分离，创建、训练、发布和跨空间动作均在产品内人工确认。
- Zustand 持久化方案、任务、数据与模型版本、工具管理、确认记录及跨空间交接。演示计算使用确定性数据，不调用外部系统。
- 当前仓库已有其他模块未提交修改，保留这些修改；新实现集中在 components/compute-space 及 compute-space 路由。

## 实施单元
1. 共享模型、seed、状态机、UI 组件、样式、导航与路由（主代理）。
2. 首页、上下文、Agent 方案、跨空间交接与 PRD 检视（主代理）。
3. 任务中心、详情、运行/日志/结果、对比分析（独立 worker）。
4. 设计筛选、数据处理、模型训练/评价、科研工具发现与管理（独立 worker）。
5. 核心业务状态测试、类型检查、lint、构建；浏览器验证主链路与桌面/窄屏布局。

## 验收
- 8 张核心页面及工具详情、管理、结果对比全部可到达；旧入口映射到新页面。
- 科研方案先于任务；可编辑、版本化、确认并创建；引用的数据/模型/工具可追溯。
- 正常/异常任务有可操作状态，重试与克隆保留来源，结果可导出。
- 数据处理形成新版本，训练绑定数据版本并形成模型版本，可固定测试集评价和比较。
- 工具支持分类、详情、收藏、使用、接入、调试与发布确认。
- 读/算/做的演示交接包可查看、确认、保存与回流。
- 刷新保留演示状态；提供有确认的重置演示入口。
