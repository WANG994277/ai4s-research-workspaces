# AI4S Research Asset Hub 设计系统

> 来源优先级：科研资产 PRD V1.1 > 现有 AI4S 全局设计系统 > ui-ux-pro-max 通用建议。
> 生成器的蓝橙配色、活泼块状风格、Bento 营销布局与 PRD 冲突，因此不采用；保留其高信息密度、可访问性和交互反馈建议。

## 产品心智

- 桌面 PC Web 科研资产广场，不是仪表盘、电商商城或管理后台。
- 信息架构围绕“发现→判断→获取/使用→上传发布”展开。
- 不展示课题、项目、科研上下文、审核流、资产血缘或设备服务。

## 布局

- 保持现有 232px 左导航和 56px 顶栏；主内容以 1440×900 桌面为基准，检查 1280 与 1920。
- 广场页为“页头/搜索 + 240px 左筛选 + 可伸缩列表 + 288px 辅助信息（可选）”。
- 详情页为“Header + 水平 Tab + 主内容 + 320px 元数据侧栏”。
- 上传页为“步骤条 + 主表单 + 300px 指引/检查”。
- 仅本次验收的桌面范围内做布局；宽度不足时允许筛选栏折叠，不叠加移动端专属交互。

## 颜色与层次

| 角色 | 色值 | 用途 |
|---|---|---|
| Brand | `#B4232D` | 唯一主 CTA、活动导航、关键强调 |
| Brand hover | `#8D1B24` | 主操作悬停/按下 |
| Brand tint | `#FBECEE` | 选中筛选、弱标签 |
| Canvas | `#F5F6F8` | 页面背景 |
| Surface | `#FFFFFF` | 页头、筛选、列表、详情容器 |
| Border | `#D9DDE3` | 卡片和分割线 |
| Text | `#1F2329` | 标题/正文 |
| Secondary | `#4E5969` | 说明/元数据 |
| Muted | `#86909C` | 弱辅助文字 |
| Success | `#168B68` | 已发布/完成 |
| Warning | `#B65E00` | 准备中/需操作 |
| Error | `#C62828` | 失败/下架/破坏性操作 |

- 彩色只用于类型标识和状态，不大面积铺色。
- 广场列表默认无阴影；仅弹层、菜单和抬起侧板使用阴影。

## 字体与密度

- 沿用系统中文无衬线字体，不新增远程字体依赖。
- 页面 H1 24/650，详情标题 28/650，区块 16/600，正文 14/1.65，元数据 12—13。
- 4/8px 间距栅格；列表行 48—72px，列表卡内边距 16px，大区块间距 16—24px。
- 不使用 32px+ 营销大标题，不用跨大面积的英雄区。

## 组件约束

- 广场页每屏只有一个红色主 CTA；其他为边框或文本按钮。
- 列表卡不整卡缩放，悬停只改背景/边框，150—200ms。
- 所有图标使用 Lucide，不使用 emoji；图标按钮至少 40px 热区且有 `aria-label`。
- 搜索、排序、筛选、视图切换、收藏给出可见的激活/焦点状态。
- 表单使用可见 label、必填标记、字数/格式帮助和就地错误；长表单可保存草稿。
- 动效只用于状态转换，并支持 `prefers-reduced-motion`。

## 无障碍与状态

- 正文对比度至少 4.5:1；焦点环不可移除；Tab/筛选/列表操作可键盘达到。
- 颜色不单独表达状态，必须同时展示文本或图标。
- 覆盖加载、空结果、上传/解析/下载/网络失败、无权限、已下架和版本不存在，且每个异常给出恢复操作。
- 大文件下载明确表达“准备中”和“已就绪”，不使用无反馈的假下载。

## 实现技术边界

- 复用 Next.js 16、React 19、Tailwind 4、Lucide、Radix 和现有全局 Shell。
- 演示数据与用户动作保存于本地状态/localStorage，不接入生产存储、真实上传或真实 API。
- 页面路由可直达，返回广场时保留搜索/筛选心智。
