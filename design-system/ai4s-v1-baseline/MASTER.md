# AI4S V1.0 桌面设计系统

视觉目标以用户选定的 `docs/ui-design/workbench/workbench-direction-a.png` 为唯一基线。功能、对象、状态与权限继续以V1.0 PRD和用户后续指令为准。

## 产品气质

- 中国大陆企业级科研平台：可信、克制、清晰、可追溯，适用于正式汇报和日常科研工作。
- 蓝白主色、低对比科学背景、轻量分隔和表格化业务信息；不使用营销式Hero、Bento卡片墙、霓虹、玻璃拟态或无业务意义装饰。
- 科研工作台突出Research Agent输入和科研执行状态，其他页面按发现、管理、分析三类工作模式组织。

## 布局

- 验收视口：1280×900、1440×900、1920×1080；本期不扩展移动端。
- 全局侧栏：226px（1280下同为226px，1920下238px），垂直滚动；一级模块和有定义的二级功能完整显示。
- 顶栏：58px；仅放当前页面、全局检索、Space、通知、帮助和用户。
- 页面内容：左右24px、上下22px，1920视口增加至30px；24栅格思想，间距使用8px节奏。
- 工作台：全局侧栏 + 224px会话栏 + Research Agent工作区。Agent Session和Research Task必须分开。
- 左侧菜单承载产品功能导航；页面Tabs仅用于对象详情、状态或筛选的并列信息，不能替代功能菜单。

## 字体与图标

- 字体：PingFang SC / Microsoft YaHei / Noto Sans CJK SC；不加载远程字体。
- 页面标题23–24px/680；Agent主标题29–32px/700；区块标题16px/650；正文14px；表格12–13px；辅助信息10–12px。
- 图标统一使用Lucide线性图标，18px为导航基准，操作按钮14–16px；结构图标不得用emoji或自制符号。
- AI4S品牌使用 `public/v1/ai4s-logo.png`；Research Agent背景使用 `public/v1/research-agent-banner.png`。

## 组件

- 按钮：34–38px高，6–7px圆角；每一区域最多一个最强主操作。
- 容器：8–10px圆角、1px边框；仅Agent输入和浮层使用可感知阴影。
- 表格：浅蓝灰表头、细分隔；时间、状态、操作列不换行；空值显示“—”；工具栏按搜索→高频筛选→更多筛选→主操作排列。
- 表单：默认垂直标签；长表单分组；中文输入优先失焦或提交校验；错误靠近字段并说明原因和修复方式；提交失败保留数据。
- 弹窗/抽屉：遮罩46%深蓝黑；支持Esc、焦点管理和取消路径；Human Decision使用底部抽屉。
- 空态：说明为什么为空以及适用的下一步；无下一步时不添加按钮。
- Loading：保留布局，不展示长时间空白；长任务无真实进度时只显示阶段，不制造百分比。

## 页面模式

- 工作台：会话栏、Agent输入、需要我处理、当前研究、最近科研产出；无资讯、推荐、统计卡。
- 发现型：知识、Skill、模型、科研工具、科研软件、MCP、共享仪器；搜索是首要操作，结果卡片简洁，详情回答能力/输入/输出/限制/权限。
- 管理型：资产、实验任务、试剂耗材、空间与项目管理；使用工具栏+表格+详情，不做资源商城。
- 科研管理工作台：仅聚合既有对象和事实异常；不创造新管理对象或风险分。
- 科研驾驶舱：沿用已部署主体功能，仅接受统一全局壳层；不改变已有视图、筛选、图表和下钻。

## 国内企业产品规范依据

- 侧栏适合6项以上、多层级和高频切换的企业管理产品，并允许滚动；导航提供位置线索和稳定行为。
- 工作台展示用户返场最需要关注的信息和高频操作，缩短路径，不堆叠所有功能。
- 数据按重要性、操作频率和关联程度排序；表格配合搜索、筛选、排序和分页。
- 表单字段使用可见标签、分组、帮助和就近错误；网络/系统错误使用持续告警或Toast。

## 交付检查

- 完整左侧菜单、正确选中/展开/锁定态；没有用页面Tabs替代二级功能。
- 文本对比度、键盘焦点、标签和图标说明可用；颜色不是唯一状态信号。
- 主要操作具备默认、悬停、焦点、禁用、加载、成功、失败；删除、归档、关闭和撤销共享二次确认。
- 1280/1440/1920无页面横向溢出；大表格允许容器内滚动。
- 设计QA必须以选定UI图和1440工作台截图合并比较，P0/P1/P2全部修复后才能交付。
