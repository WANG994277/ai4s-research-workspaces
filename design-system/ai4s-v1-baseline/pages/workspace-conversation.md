# 科研工作台 · 激活会话

本页覆盖 `../MASTER.md` 的工作台详情布局。视觉目标以用户提供的通用 Agent 三栏参考图为准。

## 结构

- 激活 `session` 或 `task` 后隐藏平台全局侧栏，但保留平台顶栏、当前模块和科研空间入口；Agent 三栏工作区位于科研工作台主模块内。
- 左侧固定会话导航：AI4S Research Agent 标识、新建对话、会话搜索、范围筛选、最近会话。
- 中间为唯一主会话区：标题与状态、用户/Agent消息、Agent执行卡、Human Decision、底部输入框。
- 右侧固定聊天文件区：产出、引用资料两个页签；文件点击打开详情弹窗，不进入二级页面。
- 不显示任务概览、执行轨迹、历史会话、中间产物、最终产出等页面级Tabs；不显示“返回工作台”。

## 交互

- 任务步骤作为Agent消息流内的执行卡片，不拆成详情页。
- 需要人工确认时在消息流内显示确认卡。
- 输入框固定在主会话区底部；主会话、会话列表、聊天文件分别独立滚动。
- 简单Session不显示任务执行卡；关联Task时显示状态、步骤、暂停/恢复/取消操作。
- 右侧仅展示真实 Artifact 和引用对象，不制造图表缩略图或伪文件。

## 科研空间切换

- 个人空间单独显示。
- 项目作为可展开分组，内部依次显示可选的项目空间和课题空间。
- 当前空间显示浅蓝底、品牌蓝文字和勾选；搜索项目与空间名称并自动展开命中分组。
- 继续执行权限过滤、空间状态过滤和未提交内容确认。
