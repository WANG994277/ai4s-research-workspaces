# AI4S 科学计算设计系统

## 依据与范围

依据用户提供的 6 张桌面设计图及现有科研空间蓝白设计系统；`ui-ux-pro-max --design-system` 的通用深色/橙色建议与设计图冲突，因此采用设计图和当前项目规范。仅覆盖桌面 Web。

- 主色 `#0969f6`，悬停 `#0057d9`；页面背景 `#f4f8fd`，卡片 `#fff`，边框 `#dbe6f4`。
- 左侧平台导航直接继承其他模块的统一样式，不对科学计算路由单独改色。
- 标题 `#102a56`，正文 `#28466f`，次要信息 `#6c80a0`；系统中文字体 PingFang SC / Microsoft YaHei。
- 状态：运行中蓝、排队中橙、已完成绿、失败/停止红；状态始终显示文字。
- 页面：面包屑 → 标题/说明/主操作 → 分类标签 → 高密度任务表 → 资源与事件概览。运行详情使用顶部进度卡、参数扫描表、收敛曲线、日志与环境信息；完成详情使用结果标签、收敛图、扫描结果和文件表。
- 间距按 4/8px 节奏；卡片圆角 8px，表格紧凑，边框与浅阴影；图标统一 Lucide。
- 交互：搜索、筛选、分页、抽屉提交、状态操作、详情标签、日志/文件下载都有可见反馈。键盘焦点可见，图表有文本值与表格备份。
- 验收视口 1280×900、1440×900、1920×1080。
