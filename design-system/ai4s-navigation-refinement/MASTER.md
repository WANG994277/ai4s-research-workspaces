# AI4S 桌面功能导航规范

本规范是 `../ai4s-v1-baseline/MASTER.md` 的导航专项补充，优先于旧导航字号与间距。生成器已运行；其营销页结构、蓝橙配色和英文字体不适合现有科研平台，采用现有蓝白主题、系统中文字体与 Lucide 图标。

## 范围与复用决策

- 仅调整已有侧栏 CSS，复用 Next.js Link、Lucide、当前导航组件；无需新增组件库或依赖。
- 保留一级/二级名称、路由、角色授权和展开逻辑，后续权限合并不混入本次视觉修正。
- 侧栏宽度为 226px（大屏 238px），58px 顶栏保持一致；小屏从 210px 扩至 226px，避免滚动条出现时最长一级名称被截断，桌面验证 1280×900、1440×900、1920×1080。

## 导航尺寸

| 项目 | 规范 |
|---|---|
| 一级文字 | 14px / 22px，常规 400，选中 600 |
| 一级菜单行 | 40px 高，行间距 2px，左右内边距 12px |
| 二级文字 | 13px / 20px，常规 400，选中 600 |
| 二级菜单行 | 36px 高，行间距 0 |
| 图标 | 18×18px，禁止压缩；图标到文字 10px |
| 展开按钮 | 32×40px，箭头保持居中 |
| 侧栏菜单内边距 | 顶/左右/底 12px |
| 二级缩进 | 相对导航内容左侧 40px；与一级文字起点对齐 |
| 子菜单分组 | 上 4px，下 8px；引导线对齐一级图标中心 |
| 圆角 | 一级 6px、二级 4px |
| 底部折叠区 | 44px，固定不压缩 |

## 状态与可访问性

- 默认文字 #334155、二级文字 #52637A、箭头 #64748B；选中使用现有品牌蓝和浅蓝背景。
- 一级整行统一悬停/选中背景，不允许内部链接叠加不同底色。
- 菜单文字与图标垂直居中，所有链接清除旧的 3px 底部 margin。
- 焦点显示 2px 品牌蓝内描边；保留键盘导航和减少动态效果支持。
- 多组展开时侧栏独立滚动，不缩小字体强行塞满首屏；Logo 与底部折叠操作保持固定。
- 本次仅为桌面平台设计取值，不宣称存在统一强制的平台产品尺寸标准。

## 验收

检查一级/二级实际计算字号和行高、长名称截断、折叠对齐、多组展开滚动、选中/悬停/键盘焦点，以及三个桌面视口无页面水平溢出。
