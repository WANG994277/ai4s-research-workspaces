# 科研工作台首页 · 页面规范

依据用户确认的《AI4S 已确认核心页面 ASCII 线框汇总 V1.0》和 aivantax 工作台参考模块。全局视觉继续继承 `design-system/ai4s-v1-baseline/MASTER.md`；本页覆盖旧版“无资讯、推荐”的限制。

## 页面职责

- 科研任务发起器：首页首屏保留统一 Research Agent 输入框。
- 科研事务总览：AI 推荐汇总需知悉、需决策、建议操作；科研活动按项目、实验、计算、成果形成时间线。
- 科研信息发现：常用科研任务和科研前沿提供下一步入口，不在首页展开复杂详情。

## 桌面布局

- 仅保留全局功能侧栏；首页不显示会话历史栏。进入具体科研任务或会话后恢复会话栏。
- 页面内容最大宽度 1600px，模块间距 12px，采用 8px 节奏。
- 首屏顺序：任务输入 → 常用科研任务 → AI 推荐 / 科研活动 → 最近科研任务 / 最近科研产出 → 科研前沿。
- 两组双栏均为等宽；1280px 仍保持双栏，单卡内部允许文本截断或局部滚动，整页不得横向溢出。

## 视觉与交互

- 蓝白科研平台基线；白色表面、`#DBE6F4` 边框、8–10px 圆角、极弱阴影。
- AI 推荐使用红色作为提醒和决策语义；科研活动用红色时间轴主线，成功、运行、更新均同时显示中文标签。
- 列表行保持 56–66px，标题 13px/650，说明 12px，辅助信息 11px；操作按钮不折行。
- 页签必须是可操作按钮，具有选中、悬停、键盘焦点状态；筛选变化只改变当前模块。
- 图标统一使用 Lucide，状态不得仅靠颜色表达。
- 任务输入工具栏顺序固定为“添加 / 知识与数据 / 技能 / 工具 / 模型 / 发送”，默认模型为 `deepseekV4Pro`。
- 首页推荐与科研活动复用旧项目的完整 5 条 mock；科研前沿覆盖文献、专利、标准、科研资讯及多学科组合；最近任务三条，最近产出四条。

## 数据与跳转

- AI 推荐优先复用 pending Decision、运行/等待任务和当前空间知识资源。
- 科研活动复用 Task、Experiment、Artifact 的状态与更新时间；本地原型允许补充明确标注的演示活动。
- 最近科研任务跳转 `/workspace?task=...`；最近科研产出打开现有产出详情；知识资源跳转知识中心详情。
- “查看全部”进入对应已有列表或带筛选参数的页面，不新建并行信息架构。

## 验收

- 1280×900、1440×900、1920×1080 检查；本期不做移动端。
- 首页五层结构完整；任务发起和人工决策原交互可用。
- 空态说明原因与下一步；浏览器控制台无错误或警告；键盘可访问。

## 科研助手任务页

- 采用“全局导航 / 科研任务栏 / 中间人机协作 / 右侧研究上下文”结构；线框只约束位置和功能元素，继续使用现有蓝白视觉、卡片、图标与状态样式。
- 中间顶部展示任务名称、项目/课题路径、状态、更新时间和四阶段进度；对话区独立滚动。
- 对话输入框固定在中间列底部，不能延伸到右侧面板；工具栏顺序固定为“添加 / 知识与数据 / 技能 / 工具 / deepseekV4Pro / 发送”，不再提供本地电脑/云电脑运行环境选择。
- “读 / 算 / 做”为可取消的任务模式：点击未选项进行选中，再次点击当前项恢复为未选中；切换或取消模式时清空该模式的 Skill 选择，避免隐藏标签继续随任务提交。
- 右侧固定“研究过程 / 科研产出”两个 Tab。研究过程由当前计划、执行轨迹和人工调整记录组成；科研产出支持分类、版本、状态、核心星标、选中详情和来源追溯。
- 科研助手作为独立一级模块使用 `/assistant`；任务栏默认提供文献调研、配方参数计算、实验方案生成三条连续业务会话。
- 规划节点摘要与执行详情分层：节点折叠时只显示阶段、状态和摘要；展开后按 Supervisor 派发、专业 Agent、工具调用、结果返回展示执行时间线。
- 人工确认统一使用底部选择弹框，不在对话区重复放确认卡；科研产出不放常驻详情卡，每条通过 `…` 菜单提供“下载 / 发布为资产”。
